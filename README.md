# ChainOmen

ChainOmen utilizes a distributed ledger system for real-time data processing, enabling auto-scaling and decentralized network reliability.

With ChainOmen, you get a lightweight tool that stays out of your way.

**What you get**

- ChainOmen utilizes a distributed ledger
- system for real-time data processing,
- enabling auto-scaling and decentralized network

- Pytest for testing

## Installation

1. Clone the repository: `git clone https://github.com/fuad403273/ChainOmen.git`
2. `cd ChainOmen`
3. Install in editable mode: `pip install -e .`

## Configuration

To configure ChainOmen, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
